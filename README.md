# momenti

index.html direkt im Browser öffnen. Kein Build oder Installation nötig.

- index.html: Startseite mit vollflächigem Banner und transparentem Header
- schwangerschaft.html, event.html, baby.html, familie.html: Kategorie-Unterseiten mit identischem Header
- assets/: lokale Fotos, JavaScript und Favicon
- styling/: getrennte CSS-Dateien nach Bereichen

bannerIMG.jpg ist das Startseiten-Banner. pregnancyBannerIMG.jpg gehört zu Schwangerschaft, EventBannerIMG.jpg zu Event. babybanner.jpg gehört zu Baby, familybanner.jpg zu Familie. Beide Bilder erscheinen auf den Kategorie-Unterseiten, in den Startseiten-Kacheln und im Shooting-Flyout.

Instagram-Beitragsbilder waren nicht öffentlich abrufbar. Die Seite verwendet die drei lokal bereitgestellten Originaldateien. Unbenutzte beispiel-*.jpg-Dateien werden nicht geladen. Quelleninformationen sind nur intern in assets/bildquellen.json dokumentiert.

Kein .openai-Ordner, keine Veröffentlichung. Rechtliche Angaben vor Veröffentlichung ergänzen. Alle lokalen Links und Ressourcen wurden geprüft; keine visuelle Browserprüfung verfügbar.
